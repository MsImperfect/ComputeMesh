# ComputeMesh

ComputeMesh is a decentralized peer-to-peer compute-sharing platform.

Multiple computers can join the network and contribute computational resources.
Jobs are divided into smaller tasks and distributed among available peers.

## Core Networking Concepts

- Peer-to-peer communication
- TCP
- UDP
- Peer discovery
- Resource discovery
- Heartbeats
- Failure detection
- Task distribution
- Load balancing
- Parallel computation
- Fault tolerance
- Result aggregation
